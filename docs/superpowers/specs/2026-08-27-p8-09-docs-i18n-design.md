## Overview

GitHub renders `README.md`. Clone landing, badges, and PyPI-style links stay English. Russian is a sibling the reader can open in one click.

Three English files are Path 1 (plus the docs index that lists Path 1):

| English (canonical) | Russian sibling |
|---------------------|-----------------|
| `README.md` | `README.ru.md` |
| `docs/getting-started.md` | `docs/ru/getting-started.md` |
| `docs/README.md` | `docs/ru/README.md` |

Each pair carries the same two-link header. Code blocks, flags, paths, and role names stay English in both copies. Maintenance is one sentence on both docs indexes: edit both siblings. A small pytest checks that the files exist and the headers point at each other. No translation-quality CI.

## Proposed design

### 1. File map

Create:

- `README.ru.md` — full translation of `README.md` (same sections, same command blocks).
- `docs/ru/getting-started.md` — full translation of `docs/getting-started.md`.
- `docs/ru/README.md` — translation of the Path 1 block plus index; Paths 2–4 / Reference as G5.

Edit (headers + G6 sentence only, except the Russian files are new):

- `README.md` — language header.
- `docs/getting-started.md` — language header.
- `docs/README.md` — language header + G6 sentence.

Do not edit other markdown this cycle except VERSION/CHANGELOG/ROADMAP/badges in the release commit.

### 2. Language header

Exact first user-visible language line (after the `#` title; README: after the badge block, before the tagline):

**`README.md` / `README.ru.md`:**

```markdown
**Language:** [English](README.md) · [Русский](README.ru.md)
```

**`docs/getting-started.md`:**

```markdown
**Language:** [English](getting-started.md) · [Русский](ru/getting-started.md)
```

**`docs/ru/getting-started.md`:**

```markdown
**Language:** [English](../getting-started.md) · [Русский](getting-started.md)
```

**`docs/README.md`:**

```markdown
**Language:** [English](README.md) · [Русский](ru/README.md)
```

**`docs/ru/README.md`:**

```markdown
**Language:** [English](../README.md) · [Русский](README.md)
```

Do not add a third language this cycle. Do not use flags or images for the switcher.

### 3. Translation rules

- Headings, paragraphs, table prose, list items: Russian.
- Fenced code (bash, powershell, json): copy from English, do not translate comments *inside* those fences if the English file’s comments are English commands; keep commands copy-pasteable.
- Identifiers: `agentix`, `python -m memory`, `Agent-Init.sh`, `.agent/`, `Orchestrator`, `DONE`, env `AGENTIX_*` — English.
- Internal links from a Russian page:
  - target has a sibling this cycle → link the sibling
  - otherwise → English file + `(English)` in the link text or immediately after
- `docs/ru/README.md` Path 1 item 1 → `getting-started.md`. Items 2–3 (Multi-Frontend, Architecture) → `../multi-frontend.md` and `../architecture.md` with `(English)`.
- Version badges on Russian pages may keep the same shield URLs (they show `3.11.2` after the release commit).

Tone: natural Russian a maintainer would write. No “перевод:”, no English leftover headings.

### 4. Maintenance sentence (G6)

Add to **English** `docs/README.md` (Reference or a short “Translations” paragraph after Learning Paths):

> Path 1 public pages (`README.md`, `docs/getting-started.md`, this index) have Russian siblings (`README.ru.md`, `docs/ru/…`). Edit both when the English text changes.

Same idea in Russian on `docs/ru/README.md`. Do **not** add a new `DEVELOPMENT_STANDARDS` section.

### 5. Existence test (G7)

New `memory/test_docs_i18n.py`. Hermetic, no network. Reads repo root via `Path(__file__).resolve().parent.parent`.

| Test | Assert |
|------|--------|
| `test_russian_siblings_exist` | the three Russian paths `is_file()` |
| `test_english_headers_point_ru` | `README.md` contains `README.ru.md`; `docs/getting-started.md` contains `ru/getting-started.md`; `docs/README.md` contains `ru/README.md` |
| `test_russian_headers_point_en` | `README.ru.md` contains `](README.md)`; `docs/ru/getting-started.md` contains `../getting-started.md`; `docs/ru/README.md` contains `../README.md` |

Do not parse Russian grammar. Do not require `docs/ru/` for architecture or proxy.

### 6. CLI / product

No new flags. No wizard copy changes. No dashboard templates.

## Alternatives considered

| Option | Verdict | Why |
|--------|---------|-----|
| **Hand-written Path 1 siblings + header + existence test** | **Chosen** | Matches leftover wording; GitHub landing stays English; no new toolchain. |
| Translate all `docs/*.md` | Rejected | Different done-criterion; Path 1 is the 15-minute run. |
| `getting-started.ru.md` suffix next to originals | Rejected | `docs/ru/` scales when more guides land. |
| Russian-only under `docs/ru/` including README, no `README.ru.md` | Rejected | Operators looking at GitHub’s language variants expect `README.ru.md`. |
| MkDocs i18n | Rejected | Hosting and config for three files. |
| CI “both files must change” | Rejected | Manual sync. Existence test is enough to catch a deleted sibling. |

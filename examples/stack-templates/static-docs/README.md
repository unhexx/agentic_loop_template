# Stack Template: Static Docs

Docs-only consumer project using Agentix for documentation iterations.

## Setup

1. Copy template + `examples/consumer-starter/`.
2. Spec focus: doc updates, link checks, CHANGELOG discipline.
3. Run `bash scripts/demo-loop.sh` to verify tooling.

## Suggested Layout

```
your-docs-project/
├── agentic_loop_template/
├── docs/
├── CHANGELOG.md
├── TASK_SPECIFICATION.md
└── .agent/
```

Ideal for teams adopting Agentix Hub playbooks into documentation workflows.
